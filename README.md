# 🎬 VideoStudio

VideoStudio adalah website berbasis web untuk membantu pengguna mengunduh video TikTok tanpa watermark dan mengoptimalkan video agar cocok untuk Status WhatsApp HD.

> ⚠️ Project ini masih dalam tahap **UI Pengembangan**, jadi kemungkinan masih ada bug atau fitur yang belum stabil.

---

## ✨ Fitur Utama

### 📥 TikTok Downloader HD
- Input URL video TikTok publik
- Tombol tempel link cepat
- Tampilan modern dan responsif
- Fokus pada download video TikTok tanpa watermark
- Desain clean seperti aplikasi modern

### 🟢 WhatsApp HD Optimizer
- Upload video untuk dioptimalkan
- Mendukung format:
  - MP4
  - WebM
  - MOV
- Target optimal:
  - 720p
  - 30 FPS
- Cocok untuk kebutuhan Status WhatsApp HD
- Area upload drag & drop

### 🌗 Mode Tampilan
- Mode Putih
- Mode Gelap
- UI dengan desain rounded modern
